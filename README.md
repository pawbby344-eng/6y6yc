# Парсер Wildberries и Ozon с выдачей в Telegram

Присылаешь боту запрос текстом — получаешь товары с WB и Ozon в одном
сообщении: цена, скидка, рейтинг, отзывы, ссылка. Плюс кнопки: пересортировать
по цене, показать больше позиций, выгрузить всё в CSV.

```
🔎 кофе в зёрнах 1 кг

🟣 Wildberries · от 890 ₽
1. Кофе в зернах Арабика 1 кг
   💰 1 129 ₽  1 890 ₽  −40%
   ⭐ 4.8  ·  💬 15234  ·  Jacobs
...

🔵 Ozon · от 949 ₽
1. Кофе Lavazza Qualita Oro 1 кг
   💰 1 349 ₽  ⭐ 4.9  ·  💬 3201  ·  Lavazza
```

## Установка

```bash
pip install -r requirements.txt
playwright install chromium      # нужно для Ozon
cp .env.example .env             # и вписать TG_BOT_TOKEN от @BotFather
```

## Запуск

```bash
python -m mp_parser bot                          # Telegram-бот (long polling)
python -m mp_parser search "кофе" -n 10          # разовый поиск в терминале
python -m mp_parser search "кофе" -s wb --sort price_asc -o out.csv
```

Команды бота: любой текст — поиск по обоим маркетплейсам, `/wb запрос` и
`/ozon запрос` — по одному, `/help` — справка.

## Как это работает

| Источник | Способ | Надёжность |
|---|---|---|
| Wildberries | публичный `search.wb.ru/exactmatch/.../v13/search` | высокая, ключи не нужны |
| Ozon | `composer-api.bx/page/json/v2` → Playwright → парсинг DOM | ниже: анти-бот |

**Wildberries** отдаёт готовый JSON: берём цены из `sizes[].price` (в копейках),
с откатом на старые поля `salePriceU`/`priceU`. Цены зависят от региона —
он задаётся через `WB_DEST`.

**Ozon** публичного поиска не имеет. Порядок попыток:

1. прямой запрос к `composer-api` через httpx — быстро, но часто 403;
2. Chromium через Playwright: открываем страницу поиска, получаем cookies
   анти-бота и дёргаем тот же `composer-api` из контекста страницы;
3. если и там пусто — снимаем плитки товаров с отрендеренного DOM.

Падение одного источника не ломает выдачу: второй всё равно ответит, а причина
попадёт в сообщение («Ozon не отдал выдачу»).

## Структура

```
mp_parser/
  wb.py           поиск и разбор ответа Wildberries
  ozon.py         поиск Ozon: composer-api, Playwright, DOM-фолбэк
  aggregator.py   параллельный поиск по источникам, сортировка, изоляция ошибок
  formatting.py   сборка HTML-сообщения для Telegram
  bot.py          aiogram-бот: команды, кнопки, CSV
  export.py       CSV (с BOM для Excel) и JSON
  models.py       общая модель Product
  http.py         httpx-клиент с ретраями и бэкоффом
  cache.py        TTL-кэш запросов под callback-кнопки
  config.py       настройки из окружения / .env
tests/            тесты парсеров и форматирования на записанных фикстурах
```

## Тесты

```bash
python -m pytest tests -q
```

Тесты работают на сохранённых ответах маркетплейсов (`tests/fixtures/`), сеть не
нужна: покрыты разбор обоих форматов цен WB, `cellTrackingInfo` и атомы Ozon,
дедупликация, битые ответы, экранирование HTML, лимит сообщения Telegram и
изоляция сбоя источника.

## Оговорки

* Схемы ответов у обоих маркетплейсов не документированы и меняются без
  предупреждения — если выдача опустела, начинать нужно с фикстур в тестах:
  обновить их свежим ответом и поправить разбор.
* Ozon активно борется с автоматикой. Без Playwright он будет молчать почти
  всегда; с ним — работает, но не гарантированно.
* Запросы идут с ретраями и бэкоффом; не стоит крутить бота в режиме массового
  опроса — это и грубо, и быстро приводит к бану по IP.
